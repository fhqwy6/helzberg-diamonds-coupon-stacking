## The stacking rules that decide whether your code actually works

Helzberg allows **one promo code per order**, and most of its promotions carry a "cannot be combined with any other offer" clause. That single line eliminates most of the creative math shoppers try — you can't pair the 15% code with the $50-off code, and you can't stack a percentage code on top of a sale price if the offer's fine print excludes it.

The exclusion list matters just as much as the discount itself. Per the terms quoted on groupon and discoup, promo codes generally do **not** apply to:

- Outlet and clearance merchandise
- Pre-owned jewelry (including pre-owned Rolex)
- Watches
- Care plans
- Gift cards
- Trade-ins, repairs, and appraisal services

So a 15% code on a $3,000 engagement ring is real money, while the same code on a discounted Outlet pendant will likely bounce at checkout. If you're shopping the sale sections, assume you're already getting the deal and the code won't add anything.

One more practical wrinkle: if a code refuses to apply, the usual culprits are a minimum-spend shortfall, a category exclusion, or a conflict with an automatic promotion already in your cart. Removing the auto-applied offer and retrying the code is the first thing to try.
